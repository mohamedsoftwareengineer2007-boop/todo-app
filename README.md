# Todo App

A simple task management web app built with React and Tailwind CSS.

## Features
- Add new tasks
- Mark tasks as completed
- Delete tasks

## Tech Stack
- React
- Tailwind CSS
- Lucide React (icons)

## Run Locally
1. Clone the repository
2. Run `npm install`
3. Run `npm start`
4. Open http://localhost:3000
